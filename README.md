# Glint

A little companion in your Mac's menu bar for Claude Code, Codex and Gemini CLI. It shows what your sessions are doing, and every session brings a Glint to collect: cards, packs, shinies and perfects.

**Download:** the latest `Glint.dmg` is under [Releases](https://github.com/iamadesignerusually/glint-releases/releases/latest). Open it and drag Glint into Applications.

Glint is signed ad hoc for now: the first time, right-click Glint in Applications and choose **Open**.

Glint checks this page for updates and installs them itself.
